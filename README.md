# Medio — сайт стоматологической клиники

Многостраничный сайт для стоматологии. Ручная вёрстка по макету Figma, без применения конструкторов.

🔗 **Демо:** https://ivanfedotov333.github.io/Medio-layout/

---

## Что реализовано

- **11 страниц**: главная, о нас, услуги, отдельная услуга, врачи, отдельный врач, блог, статья, контакты, запись на приём, политика конфиденциальности.
- **Адаптив** под мобильные, планшеты, десктоп.
- **Sticky-header** со сжатием при скролле.
- **Формы** с HTML5-валидацией и кастомными сообщениями.
- **Чекбокс согласия** на обработку персональных данных + страница политики.
- **Интерактив**: аккордеон отзывов, 3D-галерея, мобильное меню.
- **SEO**: семантические теги, заголовки, мета-теги.

## Стек

- HTML5
- CSS3 (BEM, mobile-first)
- JavaScript (нативный)
- Bootstrap 5 (сетка, navbar, утилиты)
